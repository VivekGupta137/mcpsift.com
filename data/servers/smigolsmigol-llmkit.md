## Overview

The **LLMKit MCP server** is a publicly available project. Review the upstream repository for installation instructions, supported tools, compatibility, permissions, and current maintenance status.

## Configuration

Configuration, transport, authentication, and runtime requirements vary by project. Open the repository before connecting and use the smallest set of credentials and permissions required.

[Open the LLMKit repository](https://github.com/smigolsmigol/llmkit) to read the latest documentation.
