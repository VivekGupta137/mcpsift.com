A thoughtful collection of MCP servers and practical guides.  
Built for people who want to get things working.

## A directory, not a marketplace.

Find a useful server, understand what it does, and go straight to its source. No accounts, paid placements, or popularity contests.

We include both open-source servers you can run yourself and public remote integrations. Availability is not a security endorsement, and some services require authentication or a paid account.

## What belongs here

- A public repository or an official documentation site.
- A clear purpose, setup instructions, and known source.
- A useful connection for an MCP-compatible client.
- An honest description of access requirements.

## Help the directory grow.

Know a server worth adding? Suggest it in the directory’s GitHub repository. An admin reviews every addition before it goes live.

Entries and guides are Markdown files, so improvements to descriptions, configuration, and tutorials can be reviewed alongside code. There is no public publishing form or account to create.
